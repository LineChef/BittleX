## 2. How to pick the run up in a new session

1. `cd rl_training/opencat-gym && ../../.venv/bin/python phase_v5.py status` and `tail -30 trained/phase_v5.log`.
2. If the watchdog is not running (`pgrep -f v5_watchdog`) and the plan is not complete and `trained/v5_halt` does not exist: `nohup bash ../../tools/v5_watchdog.sh > /dev/null 2>&1 &`.
3. Arm a Monitor on `trained/phase_v5.log` (every line is an event worth reporting: START, SCORED, ADOPTED / REJECTED, DONE, TRACK, HALT, DECISION NEEDED,
   REPORT ready). Re-arm it when it expires.
4. On `DECISION NEEDED`: read the line, give the user the numbers and a recommendation; `phase_v5.py decide SCREEN adopt|reject`, `rm trained/v5_halt`, restart the
   watchdog. On `HALT`: find the cause in the named log, fix, `rm trained/v5_halt`, restart.
5. On `REPORT ready`: publish `trained/v5_report/report.html` as an Artifact (it is self-contained), tell the user the verdict in a few lines.
- **Pitfall that already bit twice:** never put a run's process text in a shell command (`phase_v5.py run`, a tag like `v5_control_s42`, `v5_20m`): the watchdog's
  `pgrep -f "[p]hase_v5.py run"` and `run_pipeline.any_training()` match the command line of YOUR shell and think it is running (this delayed today's start by 2 min).
- Clean up as you go (`python tools/g2_cleanup.py`), commit with explicit paths, no attribution in commit messages, `CLAUDE.md` is never committed.

## 3. What was done today (in order)

1. **V4 evaluated** (findings with numbers: [`v5-training-plan.md`](v5-training-plan.md) section 1). The headline: the old static caps silently capped every V4
   run's curriculum (side-hills 8 deg, ledges 20 mm); the side-hill is lopsided (10 deg left side down 0.49 falls vs right 0.26, V3 0.19 / 0.29) and the benchmark only
   tested one side; training stacked 2.2 hazards per episode with near-constant shoves; reward is 78% imitation, 1.4% progress, 0.5% heading; the benchmark's 3.1 s
   cells could not see crossing. Neither V3 nor V4 steers on its yaw input (a fake +-30 deg offset changes the turn rate by under 0.4 deg/s).
2. **User decisions** (plan section 2): slopes and tilts in no more than 10% of episodes, dealt evenly in all four directions, no background tilt; ladder tops 10 deg
   climb / descent, 8 deg side-hill, 35 mm step-up, 40 mm step-down; gentler shoves; 7.5 s hazard-free baseline; no steering in the policy (the Pi steers), heading-blind
   screen yes; symmetric base walk parked; crossing bonus yes; scripted walk is the baseline, V3 / V4 out of the report; the 20M not held for V4's hardware walks;
   every left/right or up/down variation (shoves included) presented in equal parts.
